# Examples

Documentation-style examples that demonstrate how to use the capability-based testing framework.
These are not runnable tests — they serve as reference for backend developers writing new tests.

| File | Description |
|------|-------------|
| `capability_usage_example.py` | Shows `@requires_protocol` decorator, convenience wrappers (`@requires_window_functions`, `@requires_cte`, etc.), and runtime protocol checking on ORM models |
