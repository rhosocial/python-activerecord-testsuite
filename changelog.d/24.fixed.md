Keep the pool's per-test slot release off the POSIX locking module. `release_all` imported `fcntl` at function entry, so a serial run on Windows failed every test with `ModuleNotFoundError` even though no slot lock had ever been taken — slot locks are only ever taken by `_acquire_slot`, reachable exclusively while pooling is active. The teardown hook now returns before the import when the worker holds no slot, with regression tests covering both the serial-run path and the POSIX-only locked path.
