The pytest 9.2 compatibility module, installed as a `pytest11` entry point so it loads with the suite wherever the suite is installed: `pytest-benchmark` 5.3.0 gets back the private `item._nodeid` it still reads (upstream #321), and the `--dist=loadgroup` suffix is carried where 9.2 reads it, so an `xdist_group` marker keeps holding connected modules onto one worker. Both shims are no-ops below 9.2 and are deleted once their plugin ships the fix.
