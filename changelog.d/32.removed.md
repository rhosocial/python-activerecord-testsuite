**Breaking:** the fixtures declare models by overriding accessors, following rhosocial-activerecord#140. `__table_name__`, `__primary_key__`, `__pk_auto_generated__` and the locator dunders are no longer read by the core release, so every fixture, provider model and embedded model source now overrides `table_name()`, `primary_key()`, `pk_auto_generated()` or the matching locator method instead; the composite-key contract tests assert `pk_auto_generated()` rather than the removed attribute. 534 declarations across 55 files. A backend that provides models of its own must follow the same shape: a model with no `table_name()` override fails with `NotImplementedError` at the first read.
